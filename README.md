# AZAKEI MARKET

経済を読み、相手を読み、未来を読むカードゲーム。

**▶ 遊ぶ：https://azakeiten.github.io/azakei-market/**

ブラウザだけで遊べます。ログインもインストールも要りません。

## できること

- **CPUと対戦** — 相手を読む「読み合いCPU」と、いちばん高い点を出す「素直CPU」
- **1台をみんなで回す** — 2〜6人で1つの端末を順番に回して遊ぶ
- **オンライン対戦** — ルームコードで、離れた友だちと（端末どうしを直接つなぐ方式）
- **歴史モード** — 1964年の東京オリンピックから2022年の資源高・円安まで、本当の出来事が年代順に起きる
- **ルールブック** — クラシック版と歴史モード版のPDF（印刷用）
- **バランス検証** — CPU同士を大量に対戦させて、ルールの偏りを調べる

## ルール（クラシック）

1. 全員同じ6枚の産業カード（エネルギー・金融・製造・小売・運輸・メディア）からスタート
2. 毎ターン経済NEWSを見て1枚選び、一斉にOPEN
3. 一度使った産業はもう使えない
4. ほかの人と被らなければ +2 POINT
5. 1回だけ先物取引：次のNEWSを見て、その点数 −1 で勝負できる

4ターン終了時に合計POINTが最も高い人の勝ち。
